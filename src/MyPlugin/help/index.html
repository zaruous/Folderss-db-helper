DB Helper 도움말

Folderss 파일 관리자 안에서 Oracle·PostgreSQL·SQL Server에 접속해 객체를 찾아보고 SQL을 실행하며, 테이블 정의서와 GCM(공통 코드) 정의서를 엑셀·JSON·CSV로 만드는 플러그인입니다.

화면

  • 메뉴 막대: 파일 · 편집 · SQL · 연결 · 도구 · 도움말(Alt+F/E/S/C/T/H). 그 아래 아이콘 막대에 새 탭·열기·저장 / 실행·취소 / 커밋·롤백 / 연결·다시 연결·끊기.
  • 왼쪽 트리: DB → 스키마 → 테이블·뷰·시퀀스·프로시저/함수/패키지 → 열. 펼칠 때 불러오고 처음 1,000개를 보인 뒤 [더 보기]. 위의 검색 칸은 서버에서 스키마·객체(·열) 이름을 찾습니다.
  • SQL 탭: 탭마다 대상 DB를 정합니다. 결과는 처음 200행(1,000·5,000 선택)을 가져오고 [다음 행 가져오기]로 이어 읽습니다. 문장이 여럿이면 조회마다 결과 하위 탭이 생깁니다. 탭이 넘치면 휠로 가로 스크롤하거나 탭 줄 끝의 ▾ 목록에서 고릅니다. 탭 머리를 오른쪽 클릭하면 닫기 · 다른 탭 모두 닫기 · 왼쪽/오른쪽 탭 모두 닫기.
  • 편집기: 줄 번호가 있고 주석·문자열·키워드·자료형을 탭 대상 DB의 문법으로 색칠합니다(대상을 바꾸면 다시 칠함). 줄 간격, 대상별 색·굵게·기울임, 더 칠할·칠하지 않을 낱말, 칠하지 않을 긴 줄 기준(기본 20,000자)은 설정 › SQL 편집기 탭에서 정하고 저장하면 열린 탭이 바로 따릅니다.
  • 임시 저장: 입력이 멈추고 1.5초 뒤, 탭이나 창을 닫을 때 자동 저장되어 다음에 창을 열면 되살아납니다(파일 탭 포함). 저장 내용은 이 Windows 사용자만 풀 수 있게 잠가 둡니다. 설정 › SQL 편집기에서 접속마다 임시 저장을 끄거나 저장한 내용을 지울 수 있습니다. 파일을 끌어다 편집기에 놓으면 그 파일 탭으로 열립니다.

트랜잭션과 안전장치

  • 자동 커밋은 꺼져 있습니다. DML은 커밋 전까지 "커밋 대기"로 표시되고 [커밋]·[롤백]으로 끝냅니다. 같은 DB를 대상으로 하는 탭은 세션 하나(트랜잭션 하나)를 함께 씁니다.
  • WHERE 없는 UPDATE·DELETE, DROP·TRUNCATE·ALTER 등은 확인 체크 뒤 실행합니다. DDL은 실행 전에 대기 중인 변경을 먼저 커밋합니다(모든 DBMS에서 같게 동작).
  • 읽기 전용 접속은 플러그인 쪽 차단입니다. 운영 DB는 DB 계정 권한도 읽기 전용으로 두세요.
