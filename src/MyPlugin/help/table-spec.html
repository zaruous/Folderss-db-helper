테이블 정의서

Oracle 데이터 사전(ALL_*)을 읽어 열·인덱스·제약 조건·행 수·주석을 엑셀 양식에 채웁니다. 트리에서 테이블을 Ctrl·Shift+클릭으로 여러 개 고르거나 스키마·DB를 고른 뒤 오른쪽 메뉴, 또는 도구 > 테이블 정의서 만들기….

대상 고르기

  • 트리에서 고른 테이블은 체크되어 있습니다. 스키마를 바꿔 가며 체크해도 다른 스키마의 체크는 남습니다.
  • 정규식으로 이름(·주석)을 걸러 [일치 모두 체크]·[일치 모두 해제]. 예: ^TB_, _(M|D)$, ^(ORDER|ITEM).
  • 목록에서 여러 줄을 고른 뒤 Space로 체크·해제, 두 번 누르면 체크·해제, Ctrl+A 모두 고르기. [체크한 것만 보기]는 모든 스키마의 체크를 모아 보입니다.
  • [뷰 포함]을 켜면 뷰도 대상이 됩니다.

문서 정보와 양식

  • 문서 정보(제목·프로젝트·시스템/모듈·작성자·버전·작성일·설명)는 표지에 들어가고, [만들기…] 때 입력한 값과 고른 양식·저장 폴더는 기억합니다.
  • 양식: 기본 2종(기본 — 표지·목록(시트 링크)·테이블마다 열·인덱스·제약 조건 / 명세서형 — 논리명·키 PK/FK/UK/IX·외래키 삭제 규칙·인덱스 유형·공통 코드·개정 이력). [복사해서 고치기]로 기본 양식을 사용자 양식 폴더에 꺼내 엑셀에서 고치면 목록에 "내 양식"으로 보입니다. 다른 위치의 파일은 [템플릿 파일]로 고릅니다.
  • 양식은 엑셀 파일이고 셀에 ${table.name} 같은 변수를 쓰며 #foreach … #end 줄로 되풀이합니다. 문법·변수는 양식의 _변수 설명 시트와 작성 지침에 있습니다: table-spec-templates.
  • [LLM 지침 복사]는 지침 주소와 양식 폴더가 든 요청 글을 복사합니다. 원하는 모양을 덧붙여 LLM(Claude Code 등)에게 보내면 양식 폴더에 새 양식을 만듭니다.

알아 둘 점

  • 논리명은 Oracle에 따로 없어 주석을 나눠 씁니다: 여러 줄이면 첫 줄, 한 줄이면 첫 :·|· - 앞, 이름(설명)이면 이름 — 나머지가 설명.
  • 데이터는 스키마마다 이름 500개씩 묶어 4번(요약·열·인덱스·제약 조건) 조회합니다. 기본값·검사 조건도 읽습니다.
  • 공통 코드 후보($codes)는 검사 조건 열 IN ('A','B')에서 뽑습니다. DB의 공통 코드 테이블을 문서화하려면 GCM 정의서를 쓰세요.
  • PostgreSQL·SQL Server 접속에서는 아직 지원하지 않습니다(안내만 띄움).
